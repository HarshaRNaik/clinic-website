# Compliance overview

This document is intentionally short and concrete so the clinic can review it quickly.

## What this code covers

- patient and staff portal separation
- consent capture and purpose limitation workflow scaffolding
- retention and erasure process placeholders
- structured note review and auditability controls
- de-identification before model access
- AI usage governance and synthetic evaluation harness

## What this code does not cover

- production deployment on live patient data
- legal approval from the clinic’s counsel
- actual Google Cloud IAM control implementation
- live DLP or Vertex AI integration in production
- patient consent execution in a signed, regulator-reviewed process

## Legal review recommendation

This repository is a working engineering scaffold for a clinical safety system, not a legal compliance opinion.
